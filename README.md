MINHA ESTANTE — VERSAO ATUALIZADA

1. Abra o arquivo index.html no Firefox ou outro navegador moderno.
2. A biblioteca pessoal continua funcionando offline e guarda seus dados no navegador.
3. Para alternar a aparência, use os botões Capas e Estante de DVDs.
4. Para recomendações e lançamentos atualizados, abra Descobrir.
5. Crie uma conta/login no TMDB e acesse https://www.themoviedb.org/settings/api
6. Na página da API, solicite o acesso e copie o campo API Read Access Token (token de leitura).
7. Cole o token na área Descobrir e clique em Conectar.

O token é guardado apenas no armazenamento local deste navegador e não é incluído no backup dos títulos.
A área Descobrir precisa de internet e de um token válido. A biblioteca, o progresso e a estante de DVDs continuam locais.

A API do TMDB é gratuita para uso não comercial, conforme os termos e requisitos de atribuição do TMDB.
Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.

IMPORTANTE: faça backups periódicos pelo botão Backup. Os dados da biblioteca ficam no navegador e não são sincronizados automaticamente entre dispositivos.
